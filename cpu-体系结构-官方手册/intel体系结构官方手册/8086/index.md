如果你想深入了解8086体系结构，**Intel官方手册**绝对是最权威、最详细的信息来源。针对8086及其直接后代（如8088），最经典和核心的参考手册是：

📚 **《Intel 8086 Family User's Manual》 (1981年10月, 订单号：9800722-03)**

这个手册通常被称为 **"8086/8088 User's Manual"** 或 **"Programmer's Reference Manual"**。它是专门为8086/8088处理器及其配套芯片（如8087 FPU, 8089 IOP, 8284A Clock, 8288 Bus Controller等）编写的，内容极其全面。

### 📖 这本手册通常包含以下关键部分（具体章节可能因版本略有不同）

1. **处理器概述：** 介绍8086/8088的设计目标、主要特性、内部架构框图、寄存器结构（包括段寄存器、通用寄存器、标志寄存器）、内存分段机制、物理地址形成。
2. **指令集详解：** 这是手册的核心部分。它按功能（数据传送、算术运算、逻辑运算、字符串操作、控制转移、处理器控制）分类，**逐条详细解释每条指令**的：
   - 功能描述
   - 汇编语言格式
   - 操作码（Opcode）二进制编码
   - 对标志位的影响
   - 指令执行所需的时钟周期数（对于理解性能和时序至关重要）
   - 可能的操作数寻址方式
   - 详细的执行步骤
3. **汇编语言指南：** 介绍8086汇编语言的基本语法、伪指令（如 `DB`, `DW`, `EQU`, `SEGMENT`, `ENDS`, `PROC`, `ENDP` 等）、表达式、运算符。
4. **系统设计：** 讲解如何构建基于8086/8088的最小模式和最大模式系统，包括：
   - 引脚定义和功能（极其重要，尤其是理解总线周期、中断、DMA）
   - 时钟和复位电路设计
   - 总线时序图（读周期、写周期、中断响应周期等 - 理解硬件交互的关键）
   - 与配套芯片（8284A, 8288, 8282/8283, 8286/8287, 8259A PIC等）的连接方式。
5. **中断和异常处理：** 详细说明中断类型（硬件、软件）、中断向量表（IVT）的结构和位置、中断处理流程、可屏蔽中断（INTR）和非屏蔽中断（NMI）。
6. **配套芯片资料：** 手册通常包含8087数值协处理器、8089 I/O处理器以及828x系列支持芯片的简要或详细说明（有时这些芯片会有单独的详细手册）。
7. **附录：** 可能包含指令集按操作码排序的速查表、指令执行时间汇总表、指令按功能分类的索引等实用信息。
