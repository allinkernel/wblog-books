针对80386处理器，最核心的参考手册是：

📚 **《Intel 80386 Programmer's Reference Manual》 (1986年)**
📚 **《Intel 80386 System Software Writer's Guide》 (1987年)**
📚 **《Intel 80386 Hardware Reference Manual》 (1986年)**

这三本手册共同构成了理解80386体系结构的**黄金标准**。更重要的是，**Intel 64 and IA-32 Architectures Software Developer's Manuals (SDM)** 的雏形和核心思想就源于80386的文档体系。

### 📖 核心80386手册详解

1. **《Intel 80386 Programmer's Reference Manual》 (Order Number: 230985-001, 1986)**
   - **这是最核心的一本！** 专注于**软件视角**。
   - **内容：**
     - **寄存器集：** 详细介绍EAX, EBX, ECX, EDX, ESI, EDI, EBP, ESP, EIP, EFLAGS 等32位扩展寄存器，以及段寄存器（CS, DS, ES, SS, FS, GS）、控制寄存器（CR0-CR3）、调试寄存器（DR0-DR7）、测试寄存器（TR6-TR7）、段描述符寄存器（GDTR, LDTR, IDTR, TR）等。
     - **内存管理单元 (MMU)：** 这是386革命性的核心！详细解释：
       - **保护模式 (Protected Mode)：** 核心工作模式。
       - **分段机制 (Segmentation)：** 全局描述符表 (GDT)、局部描述符表 (LDT)、段描述符 (Segment Descriptor) 的格式和功能、段选择子 (Segment Selector)。
       - **分页机制 (Paging)：** 页目录、页表、页表项 (PTE) 格式、线性地址到物理地址的转换过程（二级页表）。这是现代操作系统虚拟内存的基础。
       - **特权级 (Privilege Levels - Rings 0-3)：** CPL, RPL, DPL 的概念和检查规则。
       - **任务状态段 (TSS) 和任务切换。**
     - **指令集详解：** 在8086指令集基础上，增加了32位操作数支持（`MOV EAX, EBX`）、新的寻址方式（特别是32位有效地址计算）、以及引入保护模式的关键新指令（如 `LMSW`, `SMSW`, `LGDT`, `LIDT`, `LLDT`, `LTR`, `MOV CRn`, `MOV DRn`, `ARPL`, `LAR`, `LSL`, `VERR`, `VERW`, `CLTS` 等）。手册会按类别（数据传送、算术、逻辑、串操作、控制转移、高级功能/系统指令）列出每条指令的格式、操作、标志影响、时钟周期（估算）和保护模式下的行为。
     - **中断和异常：** 详细定义中断向量号、异常类型（故障Fault、陷阱Trap、中止Abort）、中断描述符表 (IDT)、中断门/陷阱门/任务门、中断处理流程（包括特权级切换）。
     - **调试支持：** 调试寄存器 (DR0-DR7) 的功能和使用（设置硬件断点）。
     - **实地址模式 (Real-Address Mode) 和虚拟8086模式 (Virtual-8086 Mode)：** 兼容性模式的工作原理。
     - **初始化：** 从实模式切换到保护模式的步骤。
2. **《Intel 80386 System Software Writer's Guide》 (Order Number: 231499-001, 1987)**
   - **定位：** 面向**操作系统和系统级软件开发者**。
   - **内容：** 更侧重于**如何利用386硬件特性构建系统软件**。
     - **深入探讨保护模式编程概念：** 任务管理、多任务切换细节、中断和异常处理在保护模式下的实现、内存管理策略（分段与分页的结合使用）。
     - **操作系统关键数据结构设计：** 如何设计GDT, LDT, IDT, TSS。
     - **特权级转换机制：** 调用门 (Call Gates)、任务门、中断门/陷阱门如何实现不同特权级代码间的控制转移和参数传递。
     - **虚拟8086模式的管理：** V86监视器（V86 monitor）的设计。
     - **分页机制的高级应用。**
     - **缓存管理 (`CR3`, `PCD`, `PWT`位)。**
     - **系统初始化引导代码示例。**
     - **与80287/80387 FPU的协同工作。**
   - **重要性：** 这本书是理解现代操作系统底层硬件支持机制（任务切换、内存隔离、特权保护）的**绝佳教材**，其阐述的概念直接延续到现代x86。
3. **《Intel 80386 Hardware Reference Manual》 (Order Number: 231732-002, 1986)**
   - **定位：** 面向**硬件工程师**。
   - **内容：**
     - **详细的引脚定义和功能描述。**
     - **电气特性：** 电压、电流、时序参数（AC/DC特性）。
     - **总线操作和时序图：** 读/写周期、中断响应周期、总线仲裁、流水线/非流水线周期、地址流水线 (`NA#`)、突发传输 (`BLAST#`) 等。
     - **时钟要求 (`CLK2`)。**
     - **复位和初始化时序。**
     - **与协处理器 (80287/80387) 的接口。**
     - **与总线控制器 (如 82380, 82389) 和DMA控制器的接口考虑。**
     - **物理封装信息。**
   - **重要性：** 设计基于80386的主板或嵌入式系统必备。
